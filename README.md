# Reading List App

A simple and clean reading list app for saving, tracking, and managing books or articles you want to read.

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-ahahnosb)

## Live Demo

Visit the working app here:

https://reading-list-app-apwu.vercel.app/

## Features

- Add books or articles to your reading list
- Mark items as read or unread
- Remove completed or unwanted entries
- Simple, lightweight interface for quick tracking
- Built for easy personal use

## Tech Stack

- React / Next.js
- TypeScript
- Vercel deployment

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open your browser to the local development URL shown in the terminal

## Project Purpose

This app helps users keep a personal reading queue in one place, making it easier to organize reading goals and track progress over time.
